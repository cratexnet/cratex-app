## 關於 CrateX.app

CrateX.app 是一個快速的瀏覽器端工具平台，面向開發者、設計師、創作者和日常工作流程。本倉庫是 CrateX.app 的官方公開回饋與社群中心，不是應用程式原始碼倉庫。

### 倉庫範圍

- 請使用本倉庫提交 bug、功能建議、翻譯建議、路線圖回饋和社群討論。
- CrateX.app 的生產原始碼不會發布在本倉庫。
- CrateX.app 的名稱、Logo 和品牌資產未授權用於營運可能造成混淆的第三方產品。

### 🚀 溫馨提示

網站仍在快速發展中，新工具會陸續上線，現有分類和介面可能會調整，我們致力於打造現代、友好且易用的工具站，感謝您的理解與支援！

### ✨ 主要特色

- 🔒 多數工具預設採用本機處理
- ⚡ 多數工具會在瀏覽器中快速處理，並即時回饋結果
- 🌍 支援多語言介面
- 🆓 多數工具無需帳號即可使用
- 🔐 付費帳號可使用自有儲存空間進行加密 WebDAV 同步
- 📱 適配手機、平板和桌面裝置
- 🧩 支援安裝為 PWA 應用，方便快速存取常用工具（[什麼是 PWA？](https://developer.mozilla.org/zh-TW/docs/Web/Progressive_web_apps))

### 隱私、帳號與同步邊界

- 多數工具的輸入和結果會在瀏覽器本機處理；登入、付款、付費權益、WebDAV 同步、統計和網站安全等情境會使用必要的伺服器端能力。
- 日常使用多數工具無需登入。登入主要用於恢復付費權益、管理訂閱和使用 WebDAV 同步。
- 付費帳號可獲得更高的輸入長度、檔案大小、批次處理與複雜預覽上限，並可獲得無廣告體驗。
- WebDAV 同步會寫入您自己的儲存空間；請妥善保存復原金鑰，CrateX.app 無法在金鑰遺失後復原遠端加密同步資料。
- 預設會同步語言、主題、收藏、最近使用、工具設定和已審計的少量使用資料；不會同步 API Key、上傳檔案、目前頁面的暫時輸入或產生結果。

## 🐛 問題回饋

如果您在使用過程中遇到問題或有改進建議，歡迎透過以下方式回饋：

### GitHub Issues（推薦）

👉 [GitHub Issues](https://github.com/cratexnet/cratex-app/issues/new/choose)

### 回饋格式

為了更好地幫助您解決問題，請按照以下格式提交回饋：

#### 🐛 Bug 報告範本

```
問題描述：
- 簡要描述遇到的問題

重現步驟：
1. 開啟相關工具頁面
2. 輸入或上傳測試資料
3. 執行對應操作
4. 觀察到問題

預期結果：
- 描述您期望的正確結果

實際結果：
- 描述實際發生的情況

環境資訊：
- 瀏覽器：Chrome/Firefox/Safari 版本號
- 作業系統：Windows/Mac/iOS/Android
- 裝置：電腦/手機/平板
- 語言介面：中文/英文等

截圖（可選）：
- 如果有截圖能更好說明問題，請上傳
```

#### 💡 功能建議範本

```
建議的功能或工具：
- 簡要描述希望新增的工具、功能，或希望改進的現有體驗

使用場景：
- 什麼情況下會用到這個功能

具體需求：
- 詳細描述功能應該如何運作

優先順序：
- 高/中/低
```

#### 🌐 翻譯問題範本

```
語言：
- 哪個語言的翻譯有問題

位置：
- 在哪個頁面/工具中發現的問題

當前翻譯：
- 目前顯示的文字

建議翻譯：
- 您認為更合適的翻譯

說明（可選）：
- 為什麼這樣翻譯更好
```
