## Informazioni su CrateX.app

CrateX.app è una piattaforma veloce di strumenti basati sul browser per sviluppatori, designer, creator e flussi di lavoro quotidiani. Questo repository è l'hub pubblico ufficiale per feedback e community di CrateX.app, non il repository del codice sorgente dell'applicazione.

### Ambito del repository

- Usa questo repository per segnalazioni di bug, richieste di funzionalità, suggerimenti di traduzione, feedback sulla roadmap e discussioni della community.
- Il codice sorgente di produzione di CrateX.app non è pubblicato in questo repository.
- I nomi, i loghi e gli asset del marchio CrateX.app non sono concessi in licenza per gestire prodotti di terze parti che possano creare confusione.

### 🚀 Nota

Il sito è ancora in rapido sviluppo. Nuovi strumenti verranno lanciati continuamente e le categorie o interfacce esistenti potrebbero essere adeguate. Siamo impegnati a costruire un sito di strumenti moderno, intuitivo e facile da usare. Grazie per la tua comprensione e il tuo supporto!

### ✨ Caratteristiche principali

- 🔒 La maggior parte degli strumenti elabora localmente per impostazione predefinita
- ⚡ La maggior parte degli strumenti elabora rapidamente nel browser e restituisce un riscontro immediato
- 🌍 Supporta un'interfaccia multilingue
- 🆓 La maggior parte degli strumenti può essere usata senza account
- 🔐 Gli account a pagamento possono usare WebDAV Sync crittografato con il proprio storage
- 📱 Si adatta a smartphone, tablet e desktop
- 🧩 Installabile come PWA (Progressive Web App) per accedere rapidamente agli strumenti più utilizzati ([Che cos'è una PWA?](https://developer.mozilla.org/it/docs/Web/Progressive_web_apps))

### Limiti di privacy, account e sincronizzazione

- La maggior parte degli input e dei risultati degli strumenti viene elaborata localmente nel browser; accesso, pagamenti, vantaggi a pagamento, WebDAV Sync, statistiche e sicurezza del sito usano solo le capacità server necessarie.
- La maggior parte degli strumenti può essere usata senza accedere. L'accesso serve soprattutto a ripristinare i vantaggi a pagamento, gestire gli abbonamenti e usare WebDAV Sync.
- Gli account a pagamento ottengono limiti più alti per lunghezza dell'input, dimensione dei file, elaborazione batch e anteprime complesse, oltre a un'esperienza senza pubblicità.
- WebDAV Sync scrive nel tuo storage. Conserva la chiave di recupero in modo sicuro; CrateX.app non può recuperare i dati remoti di sincronizzazione cifrata se la chiave viene persa.
- Per impostazione predefinita, la sincronizzazione include lingua, tema, preferiti, strumenti recenti, impostazioni degli strumenti e una piccola quantità di dati d'uso verificati. Non sincronizza API key, file caricati, input temporanei della pagina corrente o risultati generati.

## 🐛 Segnalazione problemi

Se durante l'uso riscontri problemi o hai suggerimenti di miglioramento, puoi inviarci il tuo feedback con i metodi seguenti.

### GitHub Issues (consigliato)

👉 [GitHub Issues](https://github.com/cratexnet/cratex-app/issues/new/choose)

### Formato consigliato per le segnalazioni

Per aiutarci a risolvere meglio il tuo problema, ti preghiamo di inviare il feedback secondo il seguente formato:

#### 🐛 Template per bug

```
Descrizione del problema:
- Descrivi brevemente il problema riscontrato

Passi per riprodurre:
1. Apri la pagina dello strumento interessato
2. Inserisci o carica dati di test
3. Esegui l'azione corrispondente
4. Osserva il problema

Risultato atteso:
- Descrivi il risultato corretto che ti aspetti

Risultato effettivo:
- Descrivi cosa è successo realmente

Informazioni sull'ambiente:
- Browser: Chrome/Firefox/Safari + versione
- Sistema operativo: Windows/Mac/iOS/Android
- Dispositivo: Desktop/Tablet/Smartphone
- Lingua dell'interfaccia: Italiano/altre lingue

Screenshot (opzionale):
- Allegali se disponibili
```

#### 💡 Template per suggerimenti di funzionalità

```
Funzionalità o strumento proposto:
- Descrivi brevemente lo strumento o la funzionalità che vorresti aggiungere, oppure un'esperienza esistente da migliorare

Scenario d'uso:
- Quando e perché useresti questa funzionalità

Requisiti specifici:
- Descrivi in dettaglio come dovrebbe funzionare

Priorità:
- Alta/Media/Bassa
```

#### 🌐 Template per problemi di traduzione

```
Lingua:
- Quale lingua ha il problema di traduzione

Posizione:
- In quale pagina/strumento hai trovato il problema

Traduzione attuale:
- Testo attualmente visualizzato

Traduzione suggerita:
- La traduzione che ritieni più appropriata

Spiegazione (opzionale):
- Perché questa traduzione è migliore
```

### 📧 Contatto email

Se non puoi usare GitHub, puoi anche scriverci a: [support@cratex.app](mailto:support@cratex.app).  
Per una risposta più rapida e una comunicazione migliore, consigliamo comunque GitHub Issues come canale principale.

Nella mail, indica il tipo di problema e fornisci informazioni dettagliate.
