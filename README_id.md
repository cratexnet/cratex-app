## Tentang CrateX.app

CrateX.app adalah platform alat berbasis browser yang cepat untuk pengembang, desainer, kreator, dan alur kerja sehari-hari. Repositori ini adalah pusat umpan balik publik dan komunitas resmi untuk CrateX.app, bukan repositori kode sumber aplikasi.

### Cakupan repositori

- Gunakan repositori ini untuk laporan bug, permintaan fitur, saran terjemahan, umpan balik roadmap, dan diskusi komunitas.
- Kode sumber produksi CrateX.app tidak dipublikasikan di repositori ini.
- Nama, logo, dan aset merek CrateX.app tidak dilisensikan untuk mengoperasikan produk pihak ketiga yang dapat menimbulkan kebingungan.

### 🚀 Catatan

Situs web masih dalam pengembangan aktif. Alat-alat baru akan terus ditambahkan, dan kategori serta antarmuka yang ada mungkin akan disesuaikan. Kami berkomitmen untuk membangun situs alat yang modern, ramah, dan mudah digunakan. Terima kasih atas pengertian dan dukungan Anda!

### ✨ Fitur utama

- 🔒 Sebagian besar alat memproses secara lokal secara default
- ⚡ Sebagian besar alat memproses cepat di browser dan memberi hasil langsung
- 🌍 Mendukung antarmuka pengguna multibahasa
- 🆓 Sebagian besar alat dapat digunakan tanpa akun
- 🔐 Akun berbayar dapat menggunakan WebDAV Sync terenkripsi dengan penyimpanan sendiri
- 📱 Menyesuaikan dengan ponsel, tablet, dan desktop
- 🧩 Dapat dipasang sebagai aplikasi PWA untuk akses cepat ke alat-alat favorit ([Apa itu PWA?](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps))

### Batas privasi, akun, dan sinkronisasi

- Sebagian besar input dan hasil alat diproses secara lokal di browser; masuk akun, pembayaran, hak akun berbayar, WebDAV Sync, statistik, dan keamanan situs hanya menggunakan kemampuan server yang diperlukan.
- Sebagian besar alat dapat digunakan tanpa masuk akun. Masuk akun terutama digunakan untuk memulihkan hak akun berbayar, mengelola langganan, dan menggunakan WebDAV Sync.
- Akun berbayar mendapatkan batas lebih tinggi untuk panjang input, ukuran file, pemrosesan batch, dan pratinjau kompleks, serta pengalaman tanpa iklan.
- WebDAV Sync menulis ke penyimpanan Anda sendiri. Simpan kunci pemulihan dengan aman; CrateX.app tidak dapat memulihkan data sinkronisasi jarak jauh terenkripsi setelah kunci hilang.
- Secara default, sinkronisasi mencakup bahasa, tema, favorit, alat terbaru, pengaturan alat, dan sejumlah kecil data penggunaan yang telah diaudit. Sinkronisasi tidak mencakup API key, file yang diunggah, input sementara di halaman saat ini, atau hasil yang dibuat.

## 🐛 Pelaporan masalah

Jika Anda menemukan bug atau memiliki saran perbaikan, silakan kirim melalui metode berikut:

### GitHub Issues (Direkomendasikan)

👉 [GitHub Issues](https://github.com/cratexnet/cratex-app/issues/new/choose)

### Format umpan balik

Untuk membantu kami menyelesaikan masalah Anda dengan lebih baik, silakan kirimkan umpan balik dengan format berikut:

#### 🐛 Template laporan bug

```
Deskripsi masalah:
- Jelaskan secara singkat masalah yang ditemui

Langkah reproduksi:
1. Buka halaman alat terkait
2. Masukkan atau unggah data uji
3. Jalankan tindakan yang sesuai
4. Amati masalahnya

Hasil yang diharapkan:
- Jelaskan hasil yang benar yang Anda harapkan

Hasil aktual:
- Jelaskan apa yang sebenarnya terjadi

Informasi lingkungan:
- Browser: Versi Chrome/Firefox/Safari
- Sistem operasi: Windows/Mac/iOS/Android
- Perangkat: Desktop/Ponsel/Tablet
- Bahasa antarmuka: Indonesia/Inggris dll.

Screenshot (Opsional):
- Lampirkan screenshot jika ada
```

#### 💡 Template permintaan fitur

```
Fitur atau alat yang disarankan:
- Jelaskan singkat alat atau fitur yang ingin Anda tambahkan, atau pengalaman yang sudah ada yang ingin diperbaiki

Kasus penggunaan:
- Jelaskan kapan fitur ini akan digunakan

Persyaratan spesifik:
- Jelaskan secara detail bagaimana fitur tersebut seharusnya bekerja

Prioritas:
- Tinggi/Sedang/Rendah
```

#### 🌐 Template masalah terjemahan

```
Bahasa:
- Bahasa mana yang memiliki masalah terjemahan

Lokasi:
- Di halaman/alat mana masalah ditemukan

Terjemahan saat ini:
- Teks yang saat ini ditampilkan

Terjemahan yang disarankan:
- Terjemahan yang Anda anggap lebih tepat

Penjelasan (Opsional):
- Mengapa terjemahan ini lebih baik
```

### 📧 Kontak email

Jika GitHub tidak nyaman, Anda juga dapat mengirim email ke: [support@cratex.app](mailto:support@cratex.app). Untuk respons yang lebih cepat dan komunikasi yang lebih baik, kami sarankan menggunakan GitHub Issues.

Harap cantumkan jenis masalah dan berikan informasi detail dalam email.
