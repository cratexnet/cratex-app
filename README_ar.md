## حول CrateX.app

CrateX.app منصة أدوات سريعة تعمل في المتصفح للمطورين والمصممين والمبدعين وسير العمل اليومي. هذا المستودع هو مركز التغذية الراجعة والمجتمع العام الرسمي لـ CrateX.app، وليس مستودع شفرة التطبيق.

### نطاق المستودع

- استخدموا هذا المستودع للإبلاغ عن الأخطاء، وطلبات الميزات، واقتراحات الترجمة، وملاحظات خريطة الطريق، ونقاشات المجتمع.
- لا تُنشر شفرة الإنتاج الخاصة بـ CrateX.app في هذا المستودع.
- لا تمنح أسماء CrateX.app وشعاراتها وأصولها التجارية ترخيصاً لتشغيل منتجات طرف ثالث قد تسبب الالتباس.

### 🚀 إشعار

الموقع لا يزال في تطوير سريع. سيتم إطلاق أدوات جديدة باستمرار، وقد يتم تعديل الفئات والواجهات الحالية. نحن ملتزمون ببناء موقع أدوات حديث وودود وسهل الاستخدام. شكرا لتفهمكم ودعمكم!

### ✨ الميزات الرئيسية

- 🔒 معظم الأدوات تعالج محلياً بشكل افتراضي
- ⚡ تعالج معظم الأدوات بسرعة داخل المتصفح وتعرض النتائج فوراً
- 🌍 يدعم واجهة متعددة اللغات
- 🆓 يمكن استخدام معظم الأدوات دون حساب
- 🔐 يمكن للحسابات المدفوعة استخدام مزامنة WebDAV المشفرة مع التخزين الخاص بها
- 📱 يتكيف مع الهواتف والأجهزة اللوحية وأجهزة سطح المكتب
- 🧩 يمكن تثبيته كتطبيق PWA (تطبيق ويب تقدمي) للوصول بسرعة إلى الأدوات الأكثر استخداماً ([ما هي PWA؟](https://developer.mozilla.org/ar/docs/Web/Progressive_web_apps))

### حدود الخصوصية والحساب والمزامنة

- تتم معالجة معظم مدخلات الأدوات ونتائجها محلياً داخل المتصفح؛ أما تسجيل الدخول والمدفوعات ومزايا الحسابات المدفوعة وWebDAV Sync والإحصاءات وأمان الموقع فتستخدم القدرات الخادمية الضرورية فقط.
- يمكن استخدام معظم الأدوات دون تسجيل الدخول. يُستخدم تسجيل الدخول أساساً لاستعادة مزايا الحسابات المدفوعة وإدارة الاشتراكات واستخدام WebDAV Sync.
- تحصل الحسابات المدفوعة على حدود أعلى لطول الإدخال وحجم الملفات والمعالجة الدفعية والمعاينات المعقدة، إضافة إلى تجربة بلا إعلانات.
- يكتب WebDAV Sync إلى مساحة التخزين الخاصة بك. احتفظ بمفتاح الاسترداد بأمان؛ لا تستطيع CrateX.app استرداد بيانات المزامنة البعيدة المشفرة بعد فقدان المفتاح.
- افتراضياً، تشمل المزامنة اللغة والسمة والمفضلة والأدوات المستخدمة مؤخراً وإعدادات الأدوات وكمية صغيرة من بيانات الاستخدام المدققة. ولا تتم مزامنة مفاتيح API أو الملفات المرفوعة أو الإدخال المؤقت في الصفحة الحالية أو النتائج المُنشأة.

### GitHub Issues (مستحسن)

👉 [GitHub Issues](https://github.com/cratexnet/cratex-app/issues/new/choose)

لا تنشر الثغرات الأمنية في Issues العامة. اتبع [سياسة الأمان](https://github.com/cratexnet/cratex-app/security/policy) للإبلاغ عنها بشكل خاص.

### تنسيق التغذية الراجعة

لمساعدتكم بشكل أفضل في حل المشاكل، يرجى إرسال التغذية الراجعة وفقاً للتنسيق التالي:

#### 🐛 نموذج الإبلاغ عن خطأ

```
وصف المشكلة:
- اوصفوا باختصار المشكلة التي واجهتموها

خطوات إعادة الإنتاج:
1. فتح صفحة الأداة ذات الصلة
2. إدخال بيانات الاختبار أو رفعها
3. تنفيذ الإجراء المناسب
4. ملاحظة المشكلة

النتيجة المتوقعة:
- اوصفوا النتيجة الصحيحة التي تتوقعونها

النتيجة الفعلية:
- اوصفوا ما حدث فعلياً

معلومات البيئة:
- المتصفح: إصدار Chrome/Firefox/Safari
- نظام التشغيل: Windows/Mac/iOS/Android
- الجهاز: سطح المكتب/الهاتف/الجهاز اللوحي
- واجهة اللغة: العربية/الإنجليزية إلخ

لقطات الشاشة (اختياري):
- إذا كانت لقطات الشاشة يمكن أن توضح المشكلة بشكل أفضل، يرجى رفعها
```

#### 💡 نموذج طلب ميزة

```
الميزة أو الأداة المقترحة:
- اوصفوا باختصار الأداة أو الميزة التي ترغبون في إضافتها، أو تجربة حالية ترغبون في تحسينها

حالة الاستخدام:
- متى ستُستخدم هذه الميزة

المتطلبات المحددة:
- وصف مفصل لكيف يجب أن تعمل الميزة

الأولوية:
- عالية/متوسطة/منخفضة
```

#### 🌐 نموذج مشكلة الترجمة

```
اللغة:
- أي لغة تحتوي على مشاكل في الترجمة

الموقع:
- في أي صفحة/أداة تم اكتشاف المشكلة

الترجمة الحالية:
- النص المعروض حالياً

الترجمة المقترحة:
- الترجمة التي تعتقدون أنها أكثر ملاءمة

التفسير (اختياري):
- لماذا هذه الترجمة أفضل
```
