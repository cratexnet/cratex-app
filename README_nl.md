## Over CrateX.app

CrateX.app is een snel browsergebaseerd toolplatform voor ontwikkelaars, designers, makers en dagelijkse workflows. Deze repository is de officiële publieke feedback- en communityhub voor CrateX.app, niet de broncoderepository van de applicatie.

### Reikwijdte van de repository

- Gebruik deze repository voor bugmeldingen, functieverzoeken, vertaalsuggesties, roadmapfeedback en communitydiscussies.
- De productiebroncode van CrateX.app wordt niet in deze repository gepubliceerd.
- Namen, logo's en merkmaterialen van CrateX.app zijn niet gelicentieerd voor het exploiteren van verwarrende producten van derden.

### 🚀 Opmerking

De website is nog volop in ontwikkeling. Nieuwe tools worden continu toegevoegd en bestaande categorieën en interfaces kunnen worden aangepast. We streven naar een moderne, gebruiksvriendelijke toolsite. Bedankt voor uw begrip en steun!

### ✨ Belangrijkste kenmerken

- 🔒 De meeste tools verwerken standaard lokaal
- ⚡ De meeste tools verwerken snel in de browser en geven direct resultaat
- 🌍 Ondersteunt een meertalige gebruikersinterface
- 🆓 De meeste tools kunnen zonder account worden gebruikt
- 🔐 Betaalde accounts kunnen versleutelde WebDAV Sync gebruiken met eigen opslag
- 📱 Past zich aan telefoons, tablets en desktops aan
- 🧩 Kan worden geïnstalleerd als PWA‑app voor snelle toegang tot je favoriete tools ([Wat is een PWA?](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps))

### Grenzen voor privacy, account en synchronisatie

- De meeste invoer en resultaten van tools worden lokaal in de browser verwerkt; aanmelden, betalingen, betaalde voordelen, WebDAV Sync, statistieken en sitebeveiliging gebruiken alleen noodzakelijke servermogelijkheden.
- De meeste tools kunnen zonder aanmelden worden gebruikt. Aanmelden is vooral bedoeld om betaalde voordelen te herstellen, abonnementen te beheren en WebDAV Sync te gebruiken.
- Betaalde accounts krijgen hogere limieten voor invoerlengte, bestandsgrootte, batchverwerking en complexe previews, plus een advertentievrije ervaring.
- WebDAV Sync schrijft naar je eigen opslag. Bewaar je herstelsleutel veilig; CrateX.app kan externe versleutelde synchronisatiegegevens niet herstellen nadat de sleutel verloren is gegaan.
- Standaard synchroniseert CrateX.app taal, thema, favorieten, recente tools, toolinstellingen en een kleine hoeveelheid gecontroleerde gebruiksgegevens. API-sleutels, geüploade bestanden, tijdelijke invoer op de huidige pagina en gegenereerde resultaten worden niet gesynchroniseerd.

## 🐛 Problemen melden

Loop je tegen een bug aan of heb je ideeën voor verbeteringen? Maak dan een melding via de volgende methoden:

### GitHub Issues (Aanbevolen)

👉 [GitHub Issues](https://github.com/cratexnet/cratex-app/issues/new/choose)

### Feedbackformaat

Om je beter te kunnen helpen, gebruik alsjeblieft het volgende format:

#### 🐛 Bugrapportsjabloon

```
Probleembeschrijving:
- Beschrijf kort het probleem

Reproductiestappen:
1. Open de relevante toolpagina
2. Voer testgegevens in of upload ze
3. Voer de bijbehorende actie uit
4. Observeer het probleem

Verwacht resultaat:
- Beschrijf het verwachte correcte resultaat

Werkelijk resultaat:
- Beschrijf wat er daadwerkelijk gebeurde

Omgevingsinformatie:
- Browser: Chrome/Firefox/Safari versie
- Besturingssysteem: Windows/Mac/iOS/Android
- Apparaat: Desktop/Mobiel/Tablet
- Taalinterface: Nederlands/Engels enz.

Screenshots (Optioneel):
- Voeg screenshots toe indien beschikbaar
```

#### 💡 Functieverzoeksjabloon

```
Voorgestelde functie of tool:
- Beschrijf kort welke tool of functie je wilt toevoegen, of welke bestaande ervaring beter kan

Gebruiksscenario:
- Verklaar wanneer deze functie zou worden gebruikt

Specifieke vereisten:
- Beschrijf in detail hoe de functie zou moeten werken

Prioriteit:
- Hoog/Medium/Laag
```

#### 🌐 Vertaalprobleemsjabloon

```
Taal:
- Welke taal heeft vertaalproblemen

Locatie:
- Op welke pagina/tool werd het probleem gevonden

Huidige vertaling:
- De tekst die momenteel wordt weergegeven

Voorgestelde vertaling:
- De vertaling die u beter vindt

Uitleg (Optioneel):
- Waarom deze vertaling beter is
```

### 📧 E-mailcontact

Als GitHub niet handig is, kun je ons ook mailen via: [support@cratex.app](mailto:support@cratex.app). Voor snellere respons en betere communicatie raden we GitHub Issues aan.

Vermeld het type probleem en geef gedetailleerde informatie in de e-mail.
