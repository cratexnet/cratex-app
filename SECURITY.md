# Security Policy

## Supported Service

Security reports should target the current production version of CrateX.app at <https://cratex.app> or this public feedback repository.

## Reporting a Vulnerability

Do not open a public Issue for a suspected security vulnerability.

Email [support@cratex.app](mailto:support@cratex.app) with the subject line `[Security] Vulnerability report`. Include:

- the affected URL, tool, or workflow;
- a clear description of the issue and its potential impact;
- minimal reproduction steps or a proof of concept;
- relevant browser, operating system, and account details; and
- any suggested remediation, if available.

Do not include passwords, private tokens, personal documents, or unrelated user data. Use synthetic or redacted examples whenever possible.

We will review the report, request more information when necessary, and coordinate disclosure after the issue has been assessed. Please do not publish vulnerability details before that coordination is complete.

## Other Reports

For bugs, feature requests, translation feedback, and tool suggestions that are not security-sensitive, use the public [Issue chooser](https://github.com/cratexnet/cratex-app/issues/new/choose).
