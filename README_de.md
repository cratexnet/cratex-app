## Über CrateX.app

CrateX.app ist eine schnelle browserbasierte Tool-Plattform für Entwickler, Designer, Kreative und alltägliche Workflows. Dieses Repository ist der offizielle öffentliche Feedback- und Community-Hub für CrateX.app, nicht das Source-Code-Repository der Anwendung.

### Repository-Umfang

- Verwenden Sie dieses Repository für Fehlerberichte, Feature-Wünsche, Übersetzungsvorschläge, Roadmap-Feedback und Community-Diskussionen.
- Der Produktionsquellcode von CrateX.app wird in diesem Repository nicht veröffentlicht.
- Namen, Logos und Markenmaterialien von CrateX.app sind nicht für den Betrieb verwechslungsfähiger Drittanbieterprodukte lizenziert.

### 🚀 Hinweis

Die Website befindet sich noch in rascher Entwicklung. Neue Tools werden kontinuierlich eingeführt, und bestehende Kategorien und Schnittstellen können angepasst werden. Wir sind bestrebt, eine moderne, benutzerfreundliche und einfach zu bedienende Tool-Website zu erstellen. Vielen Dank für Ihr Verständnis und Ihre Unterstützung!

### ✨ Hauptmerkmale

- 🔒 Die meisten Tools verarbeiten Daten standardmäßig lokal
- ⚡ Die meisten Tools verarbeiten schnell im Browser und geben sofortige Rückmeldungen
- 🌍 Unterstützt mehrere Sprachen
- 🆓 Die meisten Tools sind ohne Konto nutzbar
- 🔐 Bezahlte Konten können verschlüsselte WebDAV Sync mit eigenem Speicher verwenden
- 📱 Passt sich an Smartphones, Tablets und Desktops an
- 🧩 Kann als PWA (Progressive Web App) installiert werden, um schneller auf häufig genutzte Tools zuzugreifen ([Was ist eine PWA?](https://developer.mozilla.org/de/docs/Web/Progressive_web_apps))

### Datenschutz-, Konto- und Synchronisierungsgrenzen

- Die meisten Eingaben und Ergebnisse der Tools werden lokal im Browser verarbeitet; Anmeldung, Zahlungen, bezahlte Vorteile, WebDAV Sync, Analysen und Website-Sicherheit nutzen nur notwendige serverseitige Funktionen.
- Die meisten Tools können ohne Anmeldung genutzt werden. Die Anmeldung dient hauptsächlich dazu, bezahlte Vorteile wiederherzustellen, Abonnements zu verwalten und WebDAV Sync zu verwenden.
- Bezahlte Konten erhalten höhere Grenzen für Eingabelänge, Dateigröße, Stapelverarbeitung und komplexe Vorschauen sowie eine werbefreie Nutzung.
- WebDAV Sync schreibt in Ihren eigenen Speicher. Bewahren Sie Ihren Wiederherstellungsschlüssel sicher auf; CrateX.app kann entfernte verschlüsselte Synchronisierungsdaten nach Verlust des Schlüssels nicht wiederherstellen.
- Standardmäßig synchronisiert werden Sprache, Design, Favoriten, zuletzt verwendete Tools, Tool-Einstellungen und eine kleine Menge geprüfter Nutzungsdaten. API-Schlüssel, hochgeladene Dateien, temporäre Eingaben auf der aktuellen Seite und generierte Ergebnisse werden nicht synchronisiert.

## 🐛 Probleme melden

Wenn Sie während der Nutzung auf Probleme stoßen oder Verbesserungsvorschläge haben, geben Sie bitte Feedback über die folgenden Methoden:

### GitHub Issues (Empfohlen)

👉 [GitHub Issues](https://github.com/cratexnet/cratex-app/issues/new/choose)

### Feedback-Format

Um Ihnen besser bei der Problemlösung zu helfen, reichen Sie bitte Feedback gemäß dem folgenden Format ein:

#### 🐛 Bug-Report-Vorlage

```
Problembeschreibung:
- Beschreiben Sie kurz das aufgetretene Problem

Reproduktionsschritte:
1. Zugehörige Tool-Seite öffnen
2. Testdaten eingeben oder hochladen
3. Passende Aktion ausführen
4. Problem beobachten

Erwartetes Ergebnis:
- Beschreiben Sie das korrekte Ergebnis, das Sie erwarten

Tatsächliches Ergebnis:
- Beschreiben Sie, was tatsächlich passiert ist

Umgebungsinformationen:
- Browser: Chrome/Firefox/Safari Version
- Betriebssystem: Windows/Mac/iOS/Android
- Gerät: Desktop/Handy/Tablet
- Sprachschnittstelle: Deutsch/Englisch usw.

Screenshots (Optional):
- Wenn Screenshots das Problem besser veranschaulichen können, bitte hochladen
```

#### 💡 Feature-Request-Vorlage

```
Vorgeschlagenes Feature oder Tool:
- Beschreiben Sie kurz das Tool oder Feature, das Sie sich wünschen, oder eine bestehende Erfahrung, die verbessert werden sollte

Anwendungsfall:
- Wann würde dieses Feature verwendet werden

Spezifische Anforderungen:
- Detaillierte Beschreibung, wie das Feature funktionieren sollte

Priorität:
- Hoch/Mittel/Niedrig
```

#### 🌐 Übersetzungsproblem-Vorlage

```
Sprache:
- Welche Sprache hat Übersetzungsprobleme

Ort:
- Auf welcher Seite/Tool wurde das Problem gefunden

Aktuelle Übersetzung:
- Der aktuell angezeigte Text

Vorgeschlagene Übersetzung:
- Übersetzung, die Sie für angemessener halten

Erklärung (Optional):
- Warum diese Übersetzung besser ist
```

### 📧 E-Mail-Kontakt

Wenn Sie GitHub nicht bequem nutzen können, können Sie uns auch per E-Mail kontaktieren: [support@cratex.app](mailto:support@cratex.app). Für eine schnellere Antwort und bessere Kommunikation empfehlen wir die Verwendung von GitHub Issues.

Bitte geben Sie den Problemtyp an und stellen Sie detaillierte Informationen in der E-Mail bereit.
