## О CrateX.app

CrateX.app — быстрая платформа браузерных инструментов для разработчиков, дизайнеров, создателей контента и повседневных рабочих процессов. Этот репозиторий является официальным публичным центром обратной связи и сообщества CrateX.app, а не репозиторием исходного кода приложения.

### Область репозитория

- Используйте этот репозиторий для сообщений об ошибках, запросов функций, предложений по переводу, отзывов о дорожной карте и обсуждений сообщества.
- Продакшен-исходный код CrateX.app не публикуется в этом репозитории.
- Названия, логотипы и брендовые материалы CrateX.app не лицензируются для запуска вводящих в заблуждение сторонних продуктов.

### 🚀 Уведомление

Веб-сайт все еще находится в стадии быстрой разработки. Новые инструменты будут запускаться непрерывно, а существующие категории и интерфейсы могут корректироваться. Мы стремимся создать современный, дружелюбный и простой в использовании сайт инструментов. Спасибо за ваше понимание и поддержку!

### ✨ Основные функции

- 🔒 Большинство инструментов по умолчанию обрабатывают локально
- ⚡ Большинство инструментов быстро обрабатывают данные в браузере и сразу возвращают результат
- 🌍 Многоязычный интерфейс
- 🆓 Большинством инструментов можно пользоваться без аккаунта
- 🔐 Платные аккаунты могут использовать зашифрованный WebDAV Sync со своим хранилищем
- 📱 Адаптируется к телефонам, планшетам и настольным компьютерам
- 🧩 Можно установить как PWA (Progressive Web App), чтобы быстрее получать доступ к часто используемым инструментам ([Что такое PWA?](https://developer.mozilla.org/ru/docs/Web/Progressive_web_apps))

### Границы приватности, аккаунта и синхронизации

- Большинство входных данных и результатов инструментов обрабатываются локально в браузере; вход, платежи, платные преимущества, WebDAV Sync, статистика и безопасность сайта используют только необходимые серверные возможности.
- Большинством инструментов можно пользоваться без входа. Вход в основном нужен для восстановления платных преимуществ, управления подписками и использования WebDAV Sync.
- Платные аккаунты получают более высокие лимиты длины ввода, размера файлов, пакетной обработки и сложного предпросмотра, а также работу без рекламы.
- WebDAV Sync записывает данные в ваше собственное хранилище. Надежно храните ключ восстановления; CrateX.app не сможет восстановить удаленные зашифрованные данные синхронизации после потери ключа.
- По умолчанию синхронизируются язык, тема, избранное, недавние инструменты, настройки инструментов и небольшой объем проверенных данных использования. API-ключи, загруженные файлы, временный ввод на текущей странице и сгенерированные результаты не синхронизируются.

## 🐛 Сообщить о проблеме

Если вы столкнулись с проблемами или у вас есть предложения по улучшению во время использования, предоставьте обратную связь следующими способами:

### GitHub Issues (Рекомендуется)

👉 [GitHub Issues](https://github.com/cratexnet/cratex-app/issues/new/choose)

### Формат обратной связи

Чтобы лучше помочь вам решить проблемы, отправляйте обратную связь в соответствии со следующим форматом:

#### 🐛 Шаблон отчета об ошибке

```
Описание проблемы:
- Кратко опишите возникшую проблему

Шаги воспроизведения:
1. Открыть страницу соответствующего инструмента
2. Ввести или загрузить тестовые данные
3. Выполнить соответствующее действие
4. Наблюдать проблему

Ожидаемый результат:
- Опишите правильный результат, который вы ожидаете

Фактический результат:
- Опишите, что произошло на самом деле

Информация об окружении:
- Браузер: Версия Chrome/Firefox/Safari
- Операционная система: Windows/Mac/iOS/Android
- Устройство: Настольный компьютер/Мобильный/Планшет
- Языковой интерфейс: Русский/Английский и т.д.

Скриншоты (Необязательно):
- Если скриншоты могут лучше проиллюстрировать проблему, загрузите их
```

#### 💡 Шаблон запроса функции

```
Предлагаемая функция или инструмент:
- Кратко опишите инструмент или функцию, которую вы хотели бы добавить, либо существующий опыт, который стоит улучшить

Случай использования:
- Когда эта функция будет использоваться

Специфические требования:
- Подробное описание того, как функция должна работать

Приоритет:
- Высокий/Средний/Низкий
```

#### 🌐 Шаблон проблемы перевода

```
Язык:
- На каком языке проблемы с переводом

Местоположение:
- На какой странице/инструменте была обнаружена проблема

Текущий перевод:
- Текст, который отображается в настоящее время

Предлагаемый перевод:
- Перевод, который вы считаете более подходящим

Объяснение (Необязательно):
- Почему этот перевод лучше
```
