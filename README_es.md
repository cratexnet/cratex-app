## Acerca de CrateX.app

CrateX.app es una plataforma rápida de herramientas basadas en el navegador para desarrolladores, diseñadores, creadores y flujos de trabajo cotidianos. Este repositorio es el centro público oficial de comentarios y comunidad de CrateX.app, no el repositorio del código fuente de la aplicación.

### Alcance del repositorio

- Use este repositorio para reportes de errores, solicitudes de funciones, sugerencias de traducción, comentarios sobre la hoja de ruta y conversaciones de la comunidad.
- El código fuente de producción de CrateX.app no se publica en este repositorio.
- Los nombres, logotipos y activos de marca de CrateX.app no están licenciados para operar productos de terceros que puedan causar confusión.

### 🚀 Aviso

El sitio web aún está en rápido desarrollo. Nuevas herramientas se lanzarán continuamente, y las categorías e interfaces existentes pueden ser ajustadas. Estamos comprometidos a construir un sitio de herramientas moderno, amigable y fácil de usar. ¡Gracias por su comprensión y apoyo!

### ✨ Características principales

- 🔒 La mayoría de las herramientas procesan localmente por defecto
- ⚡ La mayoría de las herramientas procesan rápidamente en el navegador y devuelven resultados inmediatos
- 🌍 Soporta varios idiomas
- 🆓 La mayoría de las herramientas pueden usarse sin cuenta
- 🔐 Las cuentas de pago pueden usar WebDAV Sync cifrado con su propio almacenamiento
- 📱 Se adapta a móviles, tabletas y equipos de escritorio
- 🧩 Se puede instalar como PWA (Progressive Web App) para acceder rápidamente a las herramientas más usadas ([¿Qué es una PWA?](https://developer.mozilla.org/es/docs/Web/Progressive_web_apps))

### Límites de privacidad, cuenta y sincronización

- La mayoría de las entradas y resultados de las herramientas se procesan localmente en el navegador; el inicio de sesión, los pagos, los beneficios de pago, WebDAV Sync, las estadísticas y la seguridad del sitio usan solo capacidades de servidor necesarias.
- La mayoría de las herramientas pueden usarse sin iniciar sesión. El inicio de sesión se usa principalmente para restaurar beneficios de pago, gestionar suscripciones y usar WebDAV Sync.
- Las cuentas de pago obtienen límites más altos de longitud de entrada, tamaño de archivo, procesamiento por lotes y vistas previas complejas, además de una experiencia sin anuncios.
- WebDAV Sync escribe en tu propio almacenamiento. Guarda bien tu clave de recuperación; CrateX.app no puede recuperar datos remotos de sincronización cifrada si se pierde la clave.
- De forma predeterminada, la sincronización incluye idioma, tema, favoritos, herramientas recientes, configuración de herramientas y una pequeña cantidad de datos de uso auditados. No sincroniza claves API, archivos subidos, entradas temporales de la página actual ni resultados generados.

## 🐛 Reporte de problemas

Si encuentra problemas o tiene sugerencias de mejora durante el uso, proporcione comentarios a través de los siguientes métodos:

### GitHub Issues (Recomendado)

👉 [GitHub Issues](https://github.com/cratexnet/cratex-app/issues/new/choose)

### Formato de comentarios

Para ayudarlo mejor a resolver problemas, envíe comentarios según el siguiente formato:

#### 🐛 Plantilla de reporte de errores

```
Descripción del problema:
- Describa brevemente el problema encontrado

Pasos de reproducción:
1. Abrir la página de la herramienta relacionada
2. Ingresar o subir datos de prueba
3. Ejecutar la acción correspondiente
4. Observar el problema

Resultado esperado:
- Describa el resultado correcto que espera

Resultado obtenido:
- Describa lo que realmente pasó

Información del entorno:
- Navegador: Versión de Chrome/Firefox/Safari
- Sistema operativo: Windows/Mac/iOS/Android
- Dispositivo: Escritorio/Móvil/Tableta
- Interfaz de idioma: Español/Inglés etc.

Capturas de pantalla (Opcional):
- Si las capturas de pantalla pueden ilustrar mejor el problema, súbalas
```

#### 💡 Plantilla de solicitud de característica

```
Característica o herramienta sugerida:
- Describa brevemente la herramienta o característica que desea agregar, o una experiencia existente que desea mejorar

Caso de uso:
- Cuándo se usaría esta característica

Requisitos específicos:
- Descripción detallada de cómo debería funcionar la característica

Prioridad:
- Alta/Media/Baja
```

#### 🌐 Plantilla de problema de traducción

```
Idioma:
- Qué idioma tiene problemas de traducción

Ubicación:
- En qué página/herramienta se encontró el problema

Traducción actual:
- El texto actualmente mostrado

Traducción sugerida:
- Traducción que cree más apropiada

Explicación (Opcional):
- Por qué esta traducción es mejor
```

### 📧 Contacto por correo

Si no es conveniente usar GitHub, también puede enviar un correo a: [support@cratex.app](mailto:support@cratex.app). Para una respuesta más rápida y mejor comunicación, recomendamos usar GitHub Issues.

Indique el tipo de problema y proporcione información detallada en el correo.
