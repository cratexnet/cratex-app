## CrateX.app について

CrateX.app は、開発者、デザイナー、クリエイター、日常のワークフロー向けの高速なブラウザベースのツールプラットフォームです。このリポジトリは CrateX.app の公式公開フィードバックおよびコミュニティハブであり、アプリケーションのソースコードリポジトリではありません。

### リポジトリの範囲

- このリポジトリは、バグ報告、機能要望、翻訳提案、ロードマップへのフィードバック、コミュニティでの議論に使用してください。
- CrateX.app の本番ソースコードはこのリポジトリでは公開されていません。
- CrateX.app の名称、ロゴ、ブランド資産は、混同を招く第三者製品の運営に使用するライセンスを付与するものではありません。

### 🚀 お知らせ

サイトはまだ急速に発展しており、新しいツールが続々とリリースされ、既存のカテゴリやインターフェースが調整される可能性があります。私たちは現代的で親しみやすく、使いやすいツールサイトの構築に努めています。ご理解とご協力をありがとうございます。

### ✨ 主な機能

- 🔒 ほとんどのツールは既定でローカル処理
- ⚡ 多くのツールはブラウザー内で高速に処理し、すぐに結果を返します
- 🌍 多言語インターフェースに対応
- 🆓 ほとんどのツールはアカウントなしで使えます
- 🔐 有料アカウントでは、自分のストレージで暗号化された WebDAV Sync を利用できます
- 📱 スマートフォン、タブレット、デスクトップに対応
- 🧩 PWA（Progressive Web App）としてインストール可能で、すばやくアクセスできます（[PWA とは？](https://developer.mozilla.org/ja/docs/Web/Progressive_web_apps))

### プライバシー、アカウント、同期の範囲

- ほとんどのツールの入力と結果はブラウザー内でローカル処理されます。サインイン、支払い、有料特典、WebDAV Sync、統計、サイト保護には必要なサーバー側機能のみを使用します。
- ほとんどのツールはサインインなしで利用できます。サインインは主に、有料特典の復元、サブスクリプション管理、WebDAV Sync の利用に使います。
- 有料アカウントでは、入力文字数、ファイルサイズ、一括処理、複雑なプレビューの上限が高くなり、広告なしで利用できます。
- WebDAV Sync はあなた自身のストレージに書き込みます。復旧キーは安全に保管してください。キーを失うと、CrateX.app はリモートの暗号化同期データを復旧できません。
- 既定では、言語、テーマ、お気に入り、最近使ったツール、ツール設定、監査済みの少量の利用データを同期します。API キー、アップロード済みファイル、現在ページの一時入力、生成結果は同期しません。

## 🐛 問題報告

使用中に問題が発生した場合や改善提案がある場合は、以下の方法でフィードバックをお願いします：

### GitHub Issues（推奨）

👉 [GitHub Issues](https://github.com/cratexnet/cratex-app/issues/new/choose)

### フィードバック形式

問題をより良く解決するために、以下の形式でフィードバックを送信してください：

#### 🐛 バグ報告テンプレート

```
問題の説明:
- 発生した問題を簡潔に記述

再現手順:
1. 関連するツールページを開く
2. テストデータを入力またはアップロードする
3. 該当する操作を実行する
4. 問題を確認する

期待される結果:
- 期待する正しい結果を説明

実際の結果:
- 実際に発生したことを記述

環境情報:
- ブラウザ：Chrome/Firefox/Safari バージョン
- オペレーティングシステム：Windows/Mac/iOS/Android
- デバイス：デスクトップ/モバイル/タブレット
- 言語インターフェース：日本語/英語等

スクリーンショット（任意）:
- 問題をより良く説明できるスクリーンショットがあればアップロード
```

#### 💡 機能提案テンプレート

```
提案する機能またはツール:
- 追加してほしいツールや機能、または改善してほしい既存の体験を簡潔に記述

使用場面:
- どのような場面でこの機能を使用するか

具体的な要求:
- 機能がどのように動作すべきかの詳細な説明

優先度:
- 高/中/低
```

#### 🌐 翻訳問題テンプレート

```
言語:
- 翻訳に問題がある言語

場所:
- どのページ/ツールで問題を発見したか

現在の翻訳:
- 現在表示されているテキスト

提案する翻訳:
- より適切だと思う翻訳

説明（任意）:
- なぜその翻訳の方が良いのか
```
