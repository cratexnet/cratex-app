## About CrateX.app

CrateX.app is a fast browser-based tool platform for developers, designers, creators, and everyday workflows. This repository is the official public feedback and community hub for CrateX.app, not the application source-code repository.

### Repository Scope

- Use this repository for bug reports, feature requests, translation suggestions, roadmap feedback, and community discussions.
- The production source code of CrateX.app is not published in this repository.
- CrateX.app names, logos, and brand assets are not licensed for operating confusing third-party products.

### 🚀 Notice

The website is still in rapid development. New tools will be launched continuously, and existing categories and interfaces may be adjusted. We are committed to building a modern, friendly, and easy-to-use tool site. Thank you for your understanding and support!

### ✨ Key Features

- 🔒 Most tools process locally by default
- ⚡ Most tools process quickly in the browser and return immediate feedback
- 🌍 Supports multiple languages
- 🆓 Most tools can be used without an account
- 🔐 Paid accounts can use encrypted WebDAV Sync with their own storage
- 📱 Adapts to phones, tablets, and desktops
- 🧩 Installable as a Progressive Web App (PWA) for quick access ([What is a PWA?](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps))

### Privacy, Account, and Sync Boundaries

- Most tool inputs and results are processed locally in the browser; sign-in, payments, paid entitlements, WebDAV Sync, analytics, and site security use only necessary server-side capabilities.
- Most tools can be used without signing in. Sign-in is mainly for restoring paid entitlements, managing subscriptions, and using WebDAV Sync.
- Paid accounts get higher limits for input length, file size, batch processing, and complex previews, plus an ad-free experience.
- WebDAV Sync writes to your own storage. Keep your recovery key safe; CrateX.app cannot recover remote encrypted sync data after the key is lost.
- By default, sync covers language, theme, favorites, recent tools, tool settings, and a small set of audited usage data. It does not sync API keys, uploaded files, temporary input on the current page, or generated results.

## 🐛 Issue Reporting

If you encounter problems or have suggestions for improvement during use, please provide feedback through the following methods:

### GitHub Issues (Recommended)

👉 [GitHub Issues](https://github.com/cratexnet/cratex-app/issues/new/choose)

Do not report security vulnerabilities in public Issues. Follow our [Security Policy](https://github.com/cratexnet/cratex-app/security/policy) to report them privately.

### Feedback Format

To better help you solve problems, please submit feedback according to the following format:

#### 🐛 Bug Report Template

```
Issue Description:
- Briefly describe the problem encountered

Reproduction Steps:
1. Open the related tool page
2. Enter or upload test data
3. Run the relevant action
4. Observe the issue

Expected Result:
- Describe the correct result you expect

Actual Result:
- Describe what actually happened

Environment Information:
- Browser: Chrome/Firefox/Safari + version
- Operating System: Windows/Mac/iOS/Android
- Device: Desktop/Mobile/Tablet
- Language Interface: Chinese/English etc.

Screenshots (Optional):
- Attach if available
```

#### 💡 Feature Request Template

```
Suggested Feature or Tool:
- Briefly describe the tool or feature you'd like us to add, or an existing experience you'd like improved

Use Case:
- When would this feature be used

Specific Requirements:
- Detailed description of how the feature should work

Priority:
- High/Medium/Low
```

#### 🌐 Translation Issue Template

```
Language:
- Which language has translation issues

Location:
- On which page/tool the issue was found

Current Translation:
- The text currently displayed

Suggested Translation:
- Translation you think is more appropriate

Explanation (Optional):
- Why this translation is better
```

### 📧 Email Contact

If GitHub is inconvenient, you can email us at: [support@cratex.app](mailto:support@cratex.app). For faster response and better communication, GitHub Issues is recommended as the primary channel.

Please indicate the issue type and provide detailed information in the email.
