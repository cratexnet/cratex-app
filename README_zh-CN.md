## 关于 CrateX.app

CrateX.app 是一个快速的浏览器端工具平台，面向开发者、设计师、创作者和日常工作流。本仓库是 CrateX.app 的官方公开反馈与社区中心，不是应用源码仓库。

### 仓库范围

- 请使用本仓库提交 bug、功能建议、翻译建议、路线图反馈和社区讨论。
- CrateX.app 的生产源码不会发布在本仓库。
- CrateX.app 的名称、Logo 和品牌资产未授权用于运营可能造成混淆的第三方产品。

### 🚀 温馨提示

网站仍在快速发展中，新工具会陆续上线，现有分类和界面可能会调整，我们致力于打造现代、友好且易用的工具站，感谢您的理解与支持！

### ✨ 主要特色

- 🔒 多数工具默认本地处理
- ⚡ 多数工具在浏览器中快速处理，并即时反馈结果
- 🌍 支持多语言界面
- 🆓 多数工具无需账户即可使用
- 🔐 付费账户可使用自有存储进行加密 WebDAV 同步
- 📱 适配手机、平板和桌面设备
- 🧩 支持安装为 PWA 应用，便于快速访问常用工具（[什么是 PWA？](https://developer.mozilla.org/zh-CN/docs/Web/Progressive_web_apps))

### 隐私、账号与同步边界

- 多数工具的输入和结果在浏览器本地处理；登录、支付、付费权益、WebDAV 同步、统计和站点安全等场景会使用必要的服务端能力。
- 日常使用多数工具无需登录。登录主要用于恢复付费权益、管理订阅和使用 WebDAV 同步。
- 付费账户可获得更高的输入长度、文件大小、批量处理与复杂预览上限，并可获得无广告体验。
- WebDAV 同步会写入您自己的存储；请妥善保存恢复密钥，CrateX.app 无法恢复丢失密钥后的远端加密同步数据。
- 默认同步语言、主题、收藏、最近使用、工具设置和已审计的少量使用数据；不会同步 API Key、上传文件、当前页面临时输入或生成结果。

## 🐛 问题反馈

如果您在使用过程中遇到问题或有改进建议，欢迎通过以下方式反馈：

### GitHub Issues（推荐）

👉 [GitHub Issues](https://github.com/cratexnet/cratex-app/issues/new/choose)

### 反馈格式

为了更好地帮助您解决问题，请按照以下格式提交反馈：

#### 🐛 Bug 报告模板

```
问题描述：
- 简要描述遇到的问题

复现步骤：
1. 打开相关工具页面
2. 输入或上传测试数据
3. 执行对应操作
4. 观察到问题

预期结果：
- 描述您期望的正确结果

实际结果：
- 描述实际发生的情况

环境信息：
- 浏览器：Chrome/Firefox/Safari 版本号
- 操作系统：Windows/Mac/iOS/Android
- 设备：电脑/手机/平板
- 语言界面：中文/英文等

截图（可选）：
- 如有截图请附上
```

#### 💡 功能建议模板

```
建议的功能或工具：
- 简要描述希望新增的工具、功能，或希望改进的现有体验

使用场景：
- 说明在什么情况下会用到该功能

具体需求：
- 详细描述功能应该如何工作

优先级：
- 高/中/低
```

#### 🌐 翻译问题模板

```
语言：
- 哪个语言的翻译有问题

位置：
- 在哪个页面/工具中发现的问题

当前翻译：
- 目前显示的文字

建议翻译：
- 您认为更合适的翻译

说明（可选）：
- 为什么这样翻译更好
```
