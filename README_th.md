## เกี่ยวกับ CrateX.app

CrateX.app เป็นแพลตฟอร์มเครื่องมือบนเบราว์เซอร์ที่รวดเร็วสำหรับนักพัฒนา นักออกแบบ ครีเอเตอร์ และเวิร์กโฟลว์ประจำวัน ที่เก็บนี้เป็นศูนย์กลางฟีดแบ็กสาธารณะและชุมชนอย่างเป็นทางการของ CrateX.app ไม่ใช่ที่เก็บซอร์สโค้ดของแอปพลิเคชัน

### ขอบเขตของที่เก็บ

- ใช้ที่เก็บนี้สำหรับรายงานบั๊ก คำขอฟีเจอร์ ข้อเสนอแนะการแปล ฟีดแบ็กเกี่ยวกับโรดแมป และการสนทนาในชุมชน
- ซอร์สโค้ด production ของ CrateX.app ไม่ได้เผยแพร่ในที่เก็บนี้
- ชื่อ โลโก้ และสินทรัพย์แบรนด์ของ CrateX.app ไม่ได้ให้สิทธิ์สำหรับการดำเนินผลิตภัณฑ์บุคคลที่สามที่อาจทำให้เกิดความสับสน

### 🚀 หมายเหตุ

เว็บไซต์ยังอยู่ในช่วงพัฒนาอย่างรวดเร็ว เครื่องมือใหม่จะถูกเพิ่มเข้ามาอย่างต่อเนื่อง และหมวดหมู่รวมถึงอินเทอร์เฟซที่มีอยู่อาจมีการปรับเปลี่ยน เรามุ่งมั่นที่จะสร้างเว็บไซต์เครื่องมือที่ทันสมัย เป็นมิตร และใช้งานง่าย ขอบคุณสำหรับความเข้าใจและการสนับสนุนของคุณ!

### ✨ จุดเด่นหลัก

- 🔒 เครื่องมือส่วนใหญ่ประมวลผลแบบโลคัลเป็นค่าเริ่มต้น
- ⚡ เครื่องมือส่วนใหญ่ประมวลผลอย่างรวดเร็วในเบราว์เซอร์และแสดงผลทันที
- 🌍 รองรับอินเทอร์เฟซผู้ใช้หลายภาษา
- 🆓 เครื่องมือส่วนใหญ่ใช้งานได้โดยไม่ต้องมีบัญชี
- 🔐 บัญชีแบบชำระเงินสามารถใช้ WebDAV Sync ที่เข้ารหัสกับพื้นที่จัดเก็บของตนเองได้
- 📱 ปรับให้เหมาะกับมือถือ แท็บเล็ต และเดสก์ท็อป
- 🧩 สามารถติดตั้งเป็นแอป PWA เพื่อเข้าถึงเครื่องมือที่ใช้บ่อยได้อย่างรวดเร็ว ([PWA คืออะไร?](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps))

### ขอบเขตด้านความเป็นส่วนตัว บัญชี และการซิงค์

- อินพุตและผลลัพธ์ของเครื่องมือส่วนใหญ่ประมวลผลในเบราว์เซอร์ของคุณเอง ส่วนการลงชื่อเข้าใช้ การชำระเงิน สิทธิ์แบบชำระเงิน WebDAV Sync สถิติ และความปลอดภัยของไซต์จะใช้ความสามารถฝั่งเซิร์ฟเวอร์เท่าที่จำเป็น
- เครื่องมือส่วนใหญ่ใช้งานได้โดยไม่ต้องลงชื่อเข้าใช้ การลงชื่อเข้าใช้มีไว้หลัก ๆ เพื่อกู้คืนสิทธิ์แบบชำระเงิน จัดการการสมัครสมาชิก และใช้ WebDAV Sync
- บัญชีแบบชำระเงินจะได้ขีดจำกัดที่สูงขึ้นสำหรับความยาวอินพุต ขนาดไฟล์ การประมวลผลแบบกลุ่ม และตัวอย่างที่ซับซ้อน พร้อมประสบการณ์แบบไม่มีโฆษณา
- WebDAV Sync จะเขียนไปยังพื้นที่จัดเก็บของคุณเอง โปรดเก็บกุญแจกู้คืนให้ปลอดภัย หากกุญแจสูญหาย CrateX.app จะไม่สามารถกู้คืนข้อมูลซิงค์ระยะไกลที่เข้ารหัสได้
- โดยค่าเริ่มต้น การซิงค์ครอบคลุมภาษา ธีม รายการโปรด เครื่องมือล่าสุด การตั้งค่าเครื่องมือ และข้อมูลการใช้งานที่ผ่านการตรวจสอบจำนวนเล็กน้อย โดยจะไม่ซิงค์ API Key ไฟล์ที่อัปโหลด อินพุตชั่วคราวในหน้าปัจจุบัน หรือผลลัพธ์ที่สร้างขึ้น

#### 🐛 เทมเพลตรายงานบั๊ก

```
คำอธิบายปัญหา:
- อธิบายปัญหาที่พบโดยสังเขป

ขั้นตอนการทำซ้ำ:
1. เปิดหน้าเครื่องมือที่เกี่ยวข้อง
2. ป้อนหรืออัปโหลดข้อมูลทดสอบ
3. เรียกใช้การดำเนินการที่เกี่ยวข้อง
4. พบปัญหา

ผลลัพธ์ที่คาดหวัง:
- อธิบายผลลัพธ์ที่ถูกต้องที่คุณคาดหวัง

ผลลัพธ์จริง:
- อธิบายสิ่งที่เกิดขึ้นจริง

ข้อมูลสภาพแวดล้อม:
- เบราว์เซอร์: เวอร์ชัน Chrome/Firefox/Safari
- ระบบปฏิบัติการ: Windows/Mac/iOS/Android
- อุปกรณ์: เดสก์ท็อป/มือถือ/แท็บเล็ต
- ภาษาอินเทอร์เฟซ: ไทย/อังกฤษ ฯลฯ

ภาพหน้าจอ (ไม่บังคับ):
- แนบภาพหน้าจอหากมี
```

#### 💡 เทมเพลตขอฟีเจอร์ใหม่

```
ฟีเจอร์หรือเครื่องมือที่เสนอ:
- อธิบายเครื่องมือหรือฟีเจอร์ที่อยากให้เพิ่ม หรือประสบการณ์เดิมที่อยากให้ปรับปรุงโดยสังเขป

กรณีใช้งาน:
- อธิบายว่าฟีเจอร์นี้จะถูกใช้เมื่อใด

ข้อกำหนดเฉพาะ:
- อธิบายรายละเอียดว่าฟีเจอร์ควรทำงานอย่างไร

ความสำคัญ:
- สูง/กลาง/ต่ำ
```
