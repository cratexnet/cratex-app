## O CrateX.app

CrateX.app to szybka platforma narzędzi działających w przeglądarce dla programistów, projektantów, twórców i codziennych przepływów pracy. To repozytorium jest oficjalnym publicznym centrum opinii i społeczności CrateX.app, a nie repozytorium kodu źródłowego aplikacji.

### Zakres repozytorium

- Używaj tego repozytorium do zgłaszania błędów, próśb o funkcje, sugestii tłumaczeń, opinii o roadmapie i dyskusji społeczności.
- Produkcyjny kod źródłowy CrateX.app nie jest publikowany w tym repozytorium.
- Nazwy, logo i materiały marki CrateX.app nie są licencjonowane do prowadzenia mylących produktów stron trzecich.

### 🚀 Uwaga

Strona jest wciąż w fazie aktywnego rozwoju. Nowe narzędzia będą stale dodawane, a istniejące kategorie i interfejsy mogą być dostosowywane. Dążymy do stworzenia nowoczesnej, przyjaznej i łatwej w użyciu strony narzędziowej. Dziękujemy za zrozumienie i wsparcie!

### ✨ Najważniejsze cechy

- 🔒 Większość narzędzi domyślnie przetwarza lokalnie
- ⚡ Większość narzędzi działa szybko w przeglądarce i od razu zwraca wyniki
- 🌍 Obsługa wielojęzycznego interfejsu użytkownika
- 🆓 Z większości narzędzi można korzystać bez konta
- 🔐 Płatne konta mogą korzystać z szyfrowanego WebDAV Sync we własnej przestrzeni
- 📱 Dostosowuje się do telefonów, tabletów i komputerów
- 🧩 Możliwość instalacji jako aplikacja PWA, aby szybciej otwierać najczęściej używane narzędzia ([Czym jest PWA?](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps))

### Granice prywatności, konta i synchronizacji

- Większość danych wejściowych i wyników narzędzi jest przetwarzana lokalnie w przeglądarce; logowanie, płatności, płatne uprawnienia, WebDAV Sync, statystyki i bezpieczeństwo strony korzystają tylko z niezbędnych funkcji serwerowych.
- Z większości narzędzi można korzystać bez logowania. Logowanie służy głównie do przywracania płatnych uprawnień, zarządzania subskrypcjami i używania WebDAV Sync.
- Płatne konta otrzymują wyższe limity długości danych wejściowych, rozmiaru plików, przetwarzania wsadowego i złożonych podglądów, a także brak reklam.
- WebDAV Sync zapisuje dane w Twojej własnej przestrzeni. Przechowuj klucz odzyskiwania w bezpiecznym miejscu; CrateX.app nie może odzyskać zdalnych zaszyfrowanych danych synchronizacji po utracie klucza.
- Domyślnie synchronizowane są język, motyw, ulubione, ostatnio używane narzędzia, ustawienia narzędzi i niewielka ilość audytowanych danych użycia. Klucze API, przesłane pliki, tymczasowe dane wejściowe na bieżącej stronie i wygenerowane wyniki nie są synchronizowane.

## 🐛 Zgłaszanie problemów

Jeśli napotkasz błąd lub masz propozycje ulepszeń, zgłoś je za pomocą następujących metod:

### GitHub Issues (Zalecane)

👉 [GitHub Issues](https://github.com/cratexnet/cratex-app/issues/new/choose)

### Format zgłoszenia

Aby lepiej pomóc w rozwiązaniu problemu, prosimy o przesłanie zgłoszenia w następującym formacie:

#### 🐛 Szablon zgłoszenia błędu

```
Opis problemu:
- Krótko opisz napotkany problem

Kroki reprodukcji:
1. Otwórz stronę odpowiedniego narzędzia
2. Wprowadź lub prześlij dane testowe
3. Wykonaj odpowiednią akcję
4. Zaobserwuj problem

Oczekiwany wynik:
- Opisz oczekiwany prawidłowy wynik

Rzeczywisty wynik:
- Opisz, co faktycznie się wydarzyło

Informacje o środowisku:
- Przeglądarka: wersja Chrome/Firefox/Safari
- System operacyjny: Windows/Mac/iOS/Android
- Urządzenie: Komputer/Telefon/Tablet
- Język interfejsu: Polski/Angielski itp.

Zrzuty ekranu (Opcjonalnie):
- Dołącz zrzuty ekranu, jeśli są dostępne
```

#### 💡 Szablon propozycji funkcji

```
Proponowana funkcja lub narzędzie:
- Krótko opisz narzędzie lub funkcję, którą chcesz dodać, albo istniejące doświadczenie, które warto ulepszyć

Przypadek użycia:
- Wyjaśnij, kiedy ta funkcja byłaby używana

Szczegółowe wymagania:
- Opisz szczegółowo, jak funkcja powinna działać

Priorytet:
- Wysoki/Średni/Niski
```

#### 🌐 Szablon problemu z tłumaczeniem

```
Język:
- Który język ma problem z tłumaczeniem

Lokalizacja:
- Na której stronie/narzędziu znaleziono problem

Obecne tłumaczenie:
- Aktualnie wyświetlany tekst

Sugerowane tłumaczenie:
- Tłumaczenie, które uważasz za lepsze

Wyjaśnienie (Opcjonalnie):
- Dlaczego to tłumaczenie jest lepsze
```
