## À propos de CrateX.app

CrateX.app est une plateforme rapide d'outils basés sur le navigateur pour les développeurs, les designers, les créateurs et les flux de travail du quotidien. Ce dépôt est le hub public officiel de retours et de communauté pour CrateX.app, pas le dépôt du code source de l'application.

### Périmètre du dépôt

- Utilisez ce dépôt pour les signalements de bugs, les demandes de fonctionnalités, les suggestions de traduction, les retours sur la feuille de route et les discussions communautaires.
- Le code source de production de CrateX.app n'est pas publié dans ce dépôt.
- Les noms, logos et éléments de marque de CrateX.app ne sont pas concédés sous licence pour exploiter des produits tiers susceptibles de créer une confusion.

### 🚀 Avis important

Le site web est encore en développement rapide. De nouveaux outils seront lancés en continu, et les catégories et interfaces existantes peuvent être ajustées. Nous nous engageons à construire un site d'outils moderne, convivial et facile à utiliser. Merci pour votre compréhension et votre support !

### ✨ Fonctionnalités principales

- 🔒 La plupart des outils traitent localement par défaut
- ⚡ La plupart des outils traitent rapidement dans le navigateur et renvoient un retour immédiat
- 🌍 Prend en charge une interface multilingue
- 🆓 La plupart des outils peuvent être utilisés sans compte
- 🔐 Les comptes payants peuvent utiliser WebDAV Sync chiffré avec leur propre stockage
- 📱 S'adapte aux mobiles, tablettes et ordinateurs
- 🧩 Installable en tant que PWA (Progressive Web App) pour un accès rapide ([Qu'est‑ce qu'une PWA ?](https://developer.mozilla.org/fr/docs/Web/Progressive_web_apps))

### Limites de confidentialité, de compte et de synchronisation

- La plupart des entrées et résultats des outils sont traités localement dans le navigateur ; la connexion, les paiements, les avantages payants, WebDAV Sync, les statistiques et la sécurité du site utilisent uniquement les capacités serveur nécessaires.
- La plupart des outils peuvent être utilisés sans connexion. La connexion sert surtout à restaurer les avantages payants, gérer les abonnements et utiliser WebDAV Sync.
- Les comptes payants bénéficient de limites plus élevées pour la longueur de saisie, la taille des fichiers, le traitement par lots et les aperçus complexes, ainsi que d'une expérience sans publicité.
- WebDAV Sync écrit dans votre propre stockage. Conservez votre clé de récupération en lieu sûr ; CrateX.app ne peut pas récupérer les données de synchronisation distantes chiffrées si cette clé est perdue.
- Par défaut, la synchronisation couvre la langue, le thème, les favoris, les outils récents, les paramètres d'outils et une petite quantité de données d'utilisation auditées. Elle ne synchronise pas les clés API, les fichiers téléversés, les saisies temporaires de la page actuelle ni les résultats générés.

## 🐛 Signalement de problèmes

Si vous rencontrez des problèmes ou avez des suggestions d'amélioration pendant l'utilisation, veuillez fournir des commentaires par les méthodes suivantes :

### GitHub Issues (Recommandé)

👉 [GitHub Issues](https://github.com/cratexnet/cratex-app/issues/new/choose)

Ne signalez pas de vulnérabilités de sécurité dans des Issues publiques. Suivez notre [politique de sécurité](https://github.com/cratexnet/cratex-app/security/policy) pour les signaler en privé.

### Format de commentaires

Pour mieux vous aider à résoudre les problèmes, veuillez soumettre des commentaires selon le format suivant :

#### 🐛 Modèle de rapport de bug

```
Description du problème :
- Décrivez brièvement le problème rencontré

Étapes de reproduction :
1. Ouvrir la page de l'outil concerné
2. Saisir ou téléverser des données de test
3. Exécuter l'action correspondante
4. Observer le problème

Résultat attendu :
- Décrivez le résultat correct que vous attendez

Résultat obtenu :
- Décrivez ce qui s'est réellement passé

Informations d'environnement :
- Navigateur : Version Chrome/Firefox/Safari
- Système d'exploitation : Windows/Mac/iOS/Android
- Appareil : Desktop/Mobile/Tablette
- Interface linguistique : Français/Anglais etc.

Captures d'écran (Optionnel) :
- Si des captures d'écran peuvent mieux illustrer le problème, veuillez les télécharger
```

#### 💡 Modèle de demande de fonctionnalité

```
Fonctionnalité ou outil suggéré :
- Décrivez brièvement l'outil ou la fonctionnalité à ajouter, ou une expérience existante à améliorer

Cas d'utilisation :
- Quand cette fonctionnalité serait-elle utilisée

Exigences spécifiques :
- Description détaillée de comment la fonctionnalité devrait fonctionner

Priorité :
- Haute/Moyenne/Basse
```

#### 🌐 Modèle de problème de traduction

```
Langue :
- Quelle langue a des problèmes de traduction

Emplacement :
- Sur quelle page/outil le problème a été trouvé

Traduction actuelle :
- Le texte actuellement affiché

Traduction suggérée :
- Traduction que vous pensez plus appropriée

Explication (Optionnel) :
- Pourquoi cette traduction est meilleure
```
