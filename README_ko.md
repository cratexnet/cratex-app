## CrateX.app 소개

CrateX.app은 개발자, 디자이너, 크리에이터와 일상적인 워크플로를 위한 빠른 브라우저 기반 도구 플랫폼입니다. 이 저장소는 CrateX.app의 공식 공개 피드백 및 커뮤니티 허브이며, 애플리케이션 소스 코드 저장소가 아닙니다.

### 저장소 범위

- 이 저장소는 버그 보고, 기능 요청, 번역 제안, 로드맵 피드백, 커뮤니티 논의에 사용해 주세요.
- CrateX.app의 프로덕션 소스 코드는 이 저장소에 공개되지 않습니다.
- CrateX.app의 이름, 로고, 브랜드 자산은 혼동을 일으킬 수 있는 제3자 제품 운영에 사용할 수 있도록 라이선스되지 않습니다.

### 🚀 안내사항

웹사이트는 아직 빠르게 발전하고 있으며, 새로운 도구가 지속적으로 출시되고 기존 카테고리와 인터페이스가 조정될 수 있습니다. 저희는 현대적이고 친숙하며 사용하기 쉬운 도구 사이트 구축에 최선을 다하고 있습니다. 여러분의 이해와 지원에 감사드립니다!

### ✨ 주요 기능

- 🔒 대부분의 도구는 기본적으로 로컬 처리
- ⚡ 대부분의 도구는 브라우저에서 빠르게 처리하고 즉시 결과를 제공합니다
- 🌍 다국어 인터페이스 지원
- 🆓 대부분의 도구는 계정 없이 사용할 수 있습니다
- 🔐 유료 계정은 자체 저장소로 암호화된 WebDAV Sync를 사용할 수 있습니다
- 📱 휴대폰, 태블릿, 데스크톱에 맞게 조정됩니다
- 🧩 PWA(Progressive Web App)로 설치할 수 있어 자주 사용하는 도구에 더 빠르게 접근할 수 있습니다 ([PWA란?](https://developer.mozilla.org/ko/docs/Web/Progressive_web_apps))

### 개인정보, 계정, 동기화 범위

- 대부분의 도구 입력과 결과는 브라우저에서 로컬로 처리됩니다. 로그인, 결제, 유료 혜택, WebDAV Sync, 통계, 사이트 보안에는 필요한 서버 기능만 사용합니다.
- 대부분의 도구는 로그인 없이 사용할 수 있습니다. 로그인은 주로 유료 혜택 복원, 구독 관리, WebDAV Sync 사용을 위해 필요합니다.
- 유료 계정은 입력 길이, 파일 크기, 일괄 처리, 복잡한 미리보기의 더 높은 한도와 광고 없는 경험을 받을 수 있습니다.
- WebDAV Sync는 사용자의 자체 저장소에 기록합니다. 복구 키를 안전하게 보관하세요. 키를 잃으면 CrateX.app은 원격 암호화 동기화 데이터를 복구할 수 없습니다.
- 기본적으로 언어, 테마, 즐겨찾기, 최근 사용 도구, 도구 설정, 감사된 소량의 사용 데이터를 동기화합니다. API 키, 업로드한 파일, 현재 페이지의 임시 입력, 생성된 결과는 동기화하지 않습니다.

```

3. 해당 작업 실행
4. 문제 확인

예상 결과:
- 예상하는 올바른 결과 설명

실제 결과:
- 실제로 발생한 상황 설명

환경 정보:
- 브라우저: Chrome/Firefox/Safari 버전
- 운영체제: Windows/Mac/iOS/Android
- 기기: 데스크톱/모바일/태블릿
```
